# Input data

Place the published files below in this folder, keeping their original file names.

| File name | Where to download |
| --- | --- |
| `media-2.xlsx` | Liu et al. (2026), *The MiDAS global genome catalog*, bioRxiv. Open https://doi.org/10.64898/2026.07.10.737647 and download the supplementary tables file from the "Supplementary Material" tab. |
| `41467_2021_22203_MOESM5_ESM.xlsx` | Singleton et al. (2021), *Nat. Commun.* 12, 2009. Open https://doi.org/10.1038/s41467-021-22203-2 and download **Supplementary Data 3** from the "Supplementary information" section. |
| `41467_2021_22203_MOESM15_ESM.xlsx` | Same article: **Supplementary Data 13**. |
| `midas4/` | Dueholm et al. (2022), *Nat. Commun.* 13, 1908, MiDAS 4. Download `Dueholm2021a_data.zip` (130 MB, CC BY 4.0) from https://doi.org/10.6084/m9.figshare.16566408 and extract these six files into a subfolder named `midas4`: `V13_ASVtab.txt`, `V13ASV_vs_MiDAS_4.8.sintax`, `V4_ASVtab.txt`, `V4ASV_vs_MiDAS_4.8.sintax`, `2020-07-03_Sequencing_metadata.txt`, `DataS1_210413.txt`. |

The scripts check for these files and stops with a message if any is missing.
